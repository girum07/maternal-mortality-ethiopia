# Maternal Mortality Trend in Ethiopia

## Objective
Analyze the trend of maternal mortality in Ethiopia using DHS/HDX data.

## Method
- Data cleaning using Pandas
- Feature engineering (change, year gap, rate of change)
- Visualization of trends over time

## Key Insight
Maternal mortality shows a decreasing trend across survey years.

## Tools
Python, Pandas, Matplotlib

## Structure
- data/ → raw dataset
- notebooks/ → exploratory analysis
- src/ → reusable code
- outputs/ → charts and results
